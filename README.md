# REDSMS · Проверка сообщений

Первичный отбор SMS перед ручной модерацией.

## Как проверяется сообщение

- **Правила.** Проверяются по статье 7 закона «О рекламе», рекламным признакам, ссылкам и имени отправителя. Работают в браузере.
- **Второе мнение GigaChat.** Модель смотрит на текст целиком: реклама это или уведомление, есть ли запрещённые категории, похоже ли на мошенничество. Вердикт модели — подсказка:
  - она может отправить сообщение на модерацию;
  - отклоняет только модератор.

## Данные

- **Что уходит в GigaChat (Сбер, серверы в России):** текст и имя отправителя. Номера телефонов и почта заменяются заглушками.
- **Ключ** хранится только на сервере, в браузер не попадает.
- **Журнал проверок** живёт до обновления страницы. Его можно выгрузить в CSV.

## Настройки

Задаются в «Проектах», поле «Переменные окружения».

| Переменная | Что это |
|---|---|
| `GIGACHAT_AUTH_KEY` | ключ авторизации: developers.sber.ru → проект GigaChat API → «Получить ключ». Без него работают только правила |
| `GIGACHAT_SCOPE` | `GIGACHAT_API_PERS` (физлица, по умолчанию), `GIGACHAT_API_B2B` или `GIGACHAT_API_CORP` |
| `GIGACHAT_MODEL` | по умолчанию `GigaChat` (младшая модель) |

## Технические детали

- Сертификат «Russian Trusted Root CA» лежит в `certs/`: без него API GigaChat не открывается по HTTPS.
- Запуск: Dockerfile, порт 8000, `APP_BASE_PATH` учитывается. В «Проектах» — «по адресу `/apps/<имя>/`».

Тесты:

```bash
pip install -r requirements.txt pytest && python -m pytest -q
```
